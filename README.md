The model requires a face mask dataset for training and testing.
Please follow the steps below to set it up:

Download the dataset from Kaggle:
"https://www.kaggle.com/datasets/omkargurav/face-mask-dataset"

After downloading, extract the contents of the ZIP file.

Rename the extracted folder to dataset (if it's not already named that).

Place the dataset folder in the same directory as this project file (where the Python scripts are located).

Next run this 
split_dataset->preprocess_data->train_model->test_model(if you want to)->real_time_mask_detection

FYI: The model is trained and can be used for face mask detection so no need to wasting time do the model again.
